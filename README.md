# 變美旅途｜成為自己的光 ♛

繁體中文、手機優先的「變美 × 高階能力 × 浪漫文字劇情」養成 Web App。無需登入、無需資料庫，可使用 GitHub Pages 免費部署，亦可作為 PWA 安裝至手機主畫面。

## 這個版本包含

- **8 章、48 關原創課程**：日常自律、肌膚與髮質、力量與姿態、穿搭與審美、表達與界線、財務與職涯、文化與領導、健康親密關係。
- **通關機制**：閱讀課程 → 四選一小測驗答對 → 實際完成練習並勾選 → 記錄通關。每章原始 6 關完成，解鎖下一章。
- **命運戀愛線**：每章固定一段陸言的虛構劇情；第 5 章進入戀愛篇章、第 8 章可自行選擇接受求婚、開啟婚姻模式。
- **每日邀約與情話**：戀愛線解鎖後，點開戀愛頁收取陸言的文字邀約、回覆邀約及閱讀每日情話，互動紀錄保留在本機。同一天的邀約與情話不重複計算親密值。
- **每日養成追蹤**：6 項預設習慣、可新增個人習慣、每日完成率、近 7 天記錄。
- **資料備份與擴充**：JSON 進度匯出、備份匯入，或自行匯入新課程 JSON。
- **RWD/PWA**：Android/桌面瀏覽器自適應、HTTPS 部署後可安裝、App 靜態資源可離線載入。

## 最簡單的試玩方式

直接開啟另外附上的 **`變美旅途-單檔試玩.html`**。它把圖片、課程和程式內嵌在同一檔案，不需要架設伺服器。不過一般瀏覽器對 `file://` 的儲存政策可能不同，適合先體驗；想可靠地長期使用，建議透過 GitHub Pages 部署安裝版。

## 免費上線：GitHub Pages

1. 在 [GitHub](https://github.com/) 新建一個 Public repository，例如 `beauty-journey`。
2. **解壓縮本專案 ZIP**，把裡面的 `index.html`、`content.js`、`content.json`、`manifest.webmanifest`、`service-worker.js`、`assets/` 等所有檔案／資料夾上傳至 repository 的**根目錄**。請勿只上傳 ZIP。
3. 到 repository 的 **Settings → Pages**，Source 選 **Deploy from a branch**，Branch 選 **main**，資料夾選 **/(root)**，按 Save。
4. 發布完成後打開 `https://你的帳號.github.io/beauty-journey/`。
5. Android 使用 Chrome 開啟後，可從選單選 **「安裝應用程式」或「新增至主畫面」**。不同瀏覽器名稱可能略有不同。

> 本 App 不需註冊外部 API，沒有串接付款／推播／遠端 AI。所謂「每日邀約」是使用者打開 App 時可讀取的劇情，不會在 App 關閉時發送系統通知。

## 資料如何保存？

- 儲存在**該網址 + 該瀏覽器**的 `localStorage` 中，並非 GitHub 倉庫，也沒有雲端同步。
- 換手機、換瀏覽器、清除網站資料、移除網站儲存內容後，進度可能消失。
- 請定期到 **我的 → 匯出進度 JSON** 下載備份。新裝置可以用 **我的 → 匯入備份 JSON** 恢復。
- 分享網址只會分享 App，不會分享你的個人進度。

## 新增課程

1. 於 App「我的」頁下載 **課程範例 JSON**。
2. 依相同格式編輯成陣列；`id` 必須不重複，`chapter` 為 1~8，`category` 為 `變美` 或 `能力`，`answer` 為 0~3（依 A/B/C/D 由零起算）。
3. 「我的 → 匯入自訂知識 JSON」選擇檔案，新課程就會出現在學院的「加碼」分頁。
4. 加碼課程不會重新鎖住既有通關進度。

若要直接**修改內建 48 關**，請修改 `content.json`，然後在電腦上執行 `python sync_content.py` 產生新的 `content.js`，把兩個檔案都提交 GitHub，並在更新 PWA 時修改 `service-worker.js` 的 `CACHE_NAME` 版號（例如 `v2`）。

課程範例：

```json
[
  {
    "id": "bonus-001",
    "chapter": 8,
    "category": "能力",
    "title": "練習自信演說",
    "knowledge": "先說結論，再用三點支持。",
    "challenge": "錄下一分鐘的演說並自我回顧。",
    "question": "演說最好先提供？",
    "options": ["過多細節", "清楚的主題", "長篇自介", "與主題無關的故事"],
    "answer": 1,
    "explanation": "清楚的主題有助聽眾掌握方向。"
  }
]
```

## 設計與使用說明

- 「頂級女人」在本作指擁有**自我決定權、專業能力、審美、財務素養、健康習慣與尊重他人的能力**，不是以外貌、收入或有無伴侶為人的價值排行。
- 每日任務與關卡紀錄採自我回報，不分析照片、不追蹤體重；戀愛故事是虛構互動。
- 課程為一般教育用途，不替代醫療、心理、投資或法律專業意見。
- 男主角「陸言」及所有劇情均為原創虛構人物。
